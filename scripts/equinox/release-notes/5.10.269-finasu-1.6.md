# Equinox FinaSU Edition 1.6

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission.

New kernel with **FinaSU v1.4.4**, and the same installer as 1.5, which checks the ROM's vendor modules
before flashing. Version 1.5 was not published as a separate release, so this is the first release with
that check.

## Files

- `Equinox-5.10.269-FinaSU-1.6-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig.
- `Equinox-5.10.269-FinaSU-1.6-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible.
- `FinaSU_v1.4.4_33167-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release.
  It updates earlier FinaSU managers in place.
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog.

## Before flashing

- Back up your `boot` partition first.
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel.
- Update the FinaSU manager to `v1.4.4` and let it update `ksud`.
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it.

## What 1.6 adds

- **FinaSU `v1.4.4`** (33167), up from `v1.2.1`. The UAPI is still 6. With FinaSU's 1.4 userspace, the
  r2 and 1.5 kernel could not list the kernel umount paths or report the hook type to the manager;
  1.6 can.
- **Hooks**: FinaSU's default Tracepoint backend, as before. The new SUSFS Inline backend is not enabled,
  and FinaSU's new vivo anti-root module filter stays off.
- **SUSFS stays at `eb95da0`** (v2.3.0). Newer SUSFS commits move SELinux hiding to a model that FinaSU
  does not support yet (the patch no longer calls FinaSU's functions and needs KernelSU to record the
  SELinux types and rules), so with FinaSU SELinux would be left unhidden. SUSFS will be updated once
  FinaSU adopts that model. SUSFS's priority filter (`set_priority_uid_filter`, "Hide third party apps"
  in BRENE) still has no effect with FinaSU.
- **More symbols hidden from `/proc/kallsyms`**: the ones FinaSU added since v1.2.1 (the vivo module
  filter, with `vivo_module_filter`, its parameter, the `init_module`/`finit_module` wrappers and their
  helpers, and `get_try_umount`), plus older FinaSU symbols that r2 also left visible (`add_try_umount`,
  the `preinit` parameter, `do_stop_input_hook`, `read_proxy`/`read_iter_proxy` and `release_perm_data`).
  Each new prefix was checked against a clean Equinox build and against the vendor modules of MistOS
  20261025 and Infinity-X 4.1, which also appear in `/proc/kallsyms`.
- From 1.5: the **vendor module check** (`kmicheck`) and the **`checkonly`** package.

## If you use BRENE

- Do not configure SUSFS from the FinaSU manager while you use BRENE: both write the same settings.
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI.
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE.

## Compatible ROMs

1.6 exports exactly the same symbol CRCs as r2 and 1.5, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds from Keosh with the kernel
  `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11, Infinity-X 3.12 (VANILLA,
  GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2 (20260929) and Axion 2.8 (VANILLA
  and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha Keles (20260930).
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them.

## Checks

- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added).
- Vendor module CRCs match MistOS 5.1 Beta 20261025 (the same modules as 20261024 and 20261023),
  Project Infinity-X 4.1, MistOS 5.0 Alpha 20260914 and the Keosh builds above (337 `vendor_boot` and
  390 `vendor_dlkm` modules each).
- **Tested on the phone** (POCO F5 Pro, MistOS 5.1 Beta 20261025) by booting this `Image` with
  `fastboot boot`, without flashing it: boots, 385 modules loaded and 0 rejected, root works, SELinux
  Enforcing, no panics or warnings, NoMount loaded, SUSFS v2.3.0, BBR, and `/proc/kallsyms` shows none of
  the root-revealing names.
- The installer's module check (`kmicheck` from the 1.6 zip, with the installer's options) was also run
  on the phone: compatible with MistOS 5.1 Beta 20261025 and with the phone's own `vendor_dlkm` (725
  modules, 0 problems), incompatible with AOSPA calcite. The full zip was not flashed.
