# Equinox FinaSU Edition 2.0

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission

New kernel with **FinaSU v1.5.2**. The installer, SUSFS, NoMount and everything else are the same as 1.9

## Files

- `Equinox-5.10.269-FinaSU-2.0-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-FinaSU-2.0-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `FinaSU_v1.5.2_33182-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release
  It updates earlier FinaSU managers in place
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Update the FinaSU manager to `v1.5.2` and let it update `ksud`
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it

## What 2.0 adds

- **FinaSU `v1.5.2`** (33182), up from `v1.5.0`. The UAPI is still 6
- **SELinux hiding**: it now parses the context a process writes once, against the live policy, and
  falls back to the backed-up policy only when needed; blank and newline-only security contexts are
  handled correctly
- The other two changes in `v1.5.2` do not apply to this kernel (one is for Linux 7.3 and newer, the
  other for x64 devices)
- **SUSFS moves to `v2.4.0`**: the core and the kernel hooks were updated. The v2.4.0 priority filter stays off because its command is not integrated in the manager yet
- Same Tracepoint hooks, NoMount v2.2.0, `/proc/kallsyms` filter and installer as 1.9

## If you use BRENE

- Do not configure SUSFS from the FinaSU manager while you use BRENE: both write the same settings
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE

## Compatible ROMs

2.0 exports the same symbol CRCs as 1.9, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds from Keosh with the kernel
  `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11, Infinity-X 3.12 (VANILLA,
  GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2 (20260929) and Axion 2.8 (VANILLA
  and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- Tested on the phone: boots with `fastboot boot` and was flashed to `boot_a`; 385 modules, SELinux Enforcing, root, SUSFS starts as v2.4.0
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
