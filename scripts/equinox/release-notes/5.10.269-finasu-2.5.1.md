# Equinox FinaSU Edition 2.5.1

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission

FinaSU goes to **v1.6.3**. NoMount, SUSFS, the installer and everything else are the same as 2.5

## Files

- `Equinox-5.10.269-FinaSU-2.5.1-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-FinaSU-2.5.1-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `FinaSU_v1.6.3_33204-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release
  It updates earlier FinaSU managers in place
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Update the FinaSU manager to `v1.6.3` and let it update `ksud`
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it

## What 2.5.1 adds

- **FinaSU `v1.6.3`** (33204), up from `v1.6.2`. The UAPI is still 6
- The new SELinux hook of `v1.6.3` (`inode_setxattr`) is for kernels without SUSFS and is not installed on SUSFS
  builds, so it does not apply to this edition
- The SELinux context parser now stops at the first unknown user or role, like the native one does
- Same NoMount v2.3.0, SUSFS v2.4.0, Tracepoint hooks, BBR, DroidSpaces, `/proc/kallsyms` filter and installer

## BakaSU edition

The BakaSU edition gets BakaSU's two newest commits (build fixes) in its version 2.5.1

## If you use BRENE

- Do not configure SUSFS from the FinaSU manager while you use BRENE: both write the same settings
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE

## Compatible ROMs

2.5.1 exports the same symbol CRCs as 2.0, 2.0.1 and 2.1, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds
  from Keosh with the kernel `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11,
  Infinity-X 3.12 (VANILLA, GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2
  (20260929) and Axion 2.8 (VANILLA and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha
  Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- Tested on the phone (POCO F5 Pro, MistOS 5.1 Beta 20261025): flashed to the boot partition and booted from it, 385 modules load and 0 are rejected, SELinux is Enforcing, `nm version` reports 23 (720), NoMount finishes the boot safely, SUSFS v2.4.0 is initialized, `ksud` is 1.6 with UAPI 6, no Oops or panic, and `/proc/kallsyms` shows none of the root-revealing names
- The NoMount test used one module with a single redirected file; the other new features of the driver (UID ranges, opaque and whiteout cases, the cache of pre-opened files) were not exercised
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
- Vendor module CRCs match (337 from `vendor_boot` and 390 from `vendor_dlkm`) for MistOS 5.1 Beta 20261025 and for the 11 latest Keosh builds; AOSPA and PenguinOS are still not compatible
- Infinity-X 4.1 was not rechecked in this version because its modules are no longer on the build machine
- The `/proc/kallsyms` filter was checked on the built kernel: none of the driver symbols left visible reveals root, and NoMount adds no new visible symbol
