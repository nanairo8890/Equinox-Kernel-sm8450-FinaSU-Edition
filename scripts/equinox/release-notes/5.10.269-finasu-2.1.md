# Equinox FinaSU Edition 2.1

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission

**Sorry for releasing another version so soon, only a few hours after 2.0.1.** 2.0.1 went out to hide
KernelSU's SELinux types as soon as possible, with a patch of my own. That same day FinaSU released
`v1.6.1`, which does that hiding natively and more completely and also brings security fixes, so it made
no sense to keep it waiting. If you already installed 2.0.1 nothing is wrong: 2.1 installs over it as
usual

## Files

- `Equinox-5.10.269-FinaSU-2.1-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-FinaSU-2.1-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `FinaSU_v1.6.1_33198-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release
  It updates earlier FinaSU managers in place
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Update the FinaSU manager to `v1.6.1` and let it update `ksud`
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it

## What 2.1 adds

- **FinaSU `v1.6.1`** (33198), up from `v1.5.2`. The UAPI is still 6
- **Security fixes in the manager and `ksud`**: profile names with path separators, NUL, line breaks or
  relative path components are rejected, and the arguments passed to root shell commands are quoted
- **Native SELinux hiding**: since `v1.6.0` FinaSU registers in SUSFS every type and every allow rule that
  KernelSU adds to the policy, not only `ksu` and `ksu_file` as the 2.0.1 patch did. That patch is gone
  and the FinaSU submodule is built exactly as LyraVoid releases it. FinaSU also no longer changes the
  policy sequence number in a way a stock kernel would not show
- **SUSFS priority filter**: FinaSU now dispatches the command of the SUSFS v2.4.0 priority UID filter
  ("Hide third party apps" in BRENE), which had no effect up to 2.0.1
- When the mount engine is switched to NoMount, the module directory is created first
- Same SUSFS v2.4.0, NoMount v2.2.0, Tracepoint hooks, BBR, `/proc/kallsyms` filter and installer

It still does not turn Duck Detector or similar detectors green: signals that do not come from the kernel
remain, such as the TEE (TEESimulator), the Vector/LSPosed types and the ROM's own contexts

## BakaSU edition

The BakaSU edition does not change and stays at 2.0.1. BakaSU has released nothing new since commit
`548d1dda`, which that version already includes, so this time only the FinaSU edition is updated

## If you use BRENE

- Do not configure SUSFS from the FinaSU manager while you use BRENE: both write the same settings
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE

## Compatible ROMs

2.1 exports the same symbol CRCs as 2.0 and 2.0.1, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds
  from Keosh with the kernel `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11,
  Infinity-X 3.12 (VANILLA, GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2
  (20260929) and Axion 2.8 (VANILLA and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha
  Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- Tested on the phone (MistOS 5.1 Beta 20261025): boots with `fastboot boot` and was flashed to `boot_a`;
  385 modules loaded and 0 rejected, SELinux Enforcing, root with `u:r:ksu:s0`, `ksud` 1.6.1, BBR and
  NoMount 22 (605)
- With an app's UID, SELinux queries for `ksu` and `ksu_file` are rejected just like those for a type that
  does not exist; root still sees them
- SUSFS v2.4.0 reports 10 features, the priority filter included; the filter itself was not tested in
  operation
- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
- Vendor module CRCs: 337 from `vendor_boot` and 390 from `vendor_dlkm` match MistOS 5.1 Beta 20261025,
  Infinity-X 4.1 and the stock modules
