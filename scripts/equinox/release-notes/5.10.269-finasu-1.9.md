# Equinox FinaSU Edition 1.9

Equinox Kernel by **[LF52406](https://github.com/LF52406)** for the POCO F5 Pro / Redmi K60 (`mondrian`),
FinaSU edition by **Nanairo8890** with LF52406's permission

New kernel with **FinaSU v1.5.0**. The installer, SUSFS, NoMount and everything else are the same as 1.8

## Files

- `Equinox-5.10.269-FinaSU-1.9-mondrian.zip`: AnyKernel3 zip. Flash it from a recovery or a kernel
  flasher; it checks the ROM's vendor modules and then replaces only the kernel `Image`, keeping the
  ROM's ramdisk, header and bootconfig
- `Equinox-5.10.269-FinaSU-1.9-mondrian-checkonly.zip`: the same package, named so that it only runs
  the check and flashes nothing. Use it to find out whether your ROM is compatible
- `FinaSU_v1.5.0_33174-release.apk`: the official FinaSU manager (`me.yuki.fina`), from FinaSU's release
  It updates earlier FinaSU managers in place
- `CHANGELOG.en.txt`, `CHANGELOG.es.txt`, `CHANGELOG.pt-BR.txt`, `CHANGELOG.ru.txt`: full changelog

## Before flashing

- Back up your `boot` partition first
- If you update your ROM, flash the zip again afterwards, because the ROM ships its own kernel
- Update the FinaSU manager to `v1.5.0` and let it update `ksud`
- Choose **NoMount** as the mount backend in the FinaSU manager. If you had the NoMount metamodule
  installed, remove it

## What 1.9 adds

- **FinaSU `v1.5.0`** (33174), up from `v1.4.4`. The UAPI is still 6
- **Two SELinux fixes in the kernel**, synchronized by FinaSU from upstream KernelSU: one fixes how the
  policy generation is tracked when the SELinux policy is updated at run time (for example by a module),
  and the other marks which SELinux types were in the original policy, so SELinux hiding no longer
  searches the policy tables again to tell them apart from the types FinaSU adds
- The other changes in `v1.5.0` are in the manager (module ordering) and in `ksud`
- **SUSFS stays at `eb95da0`** (v2.3.0). SUSFS v2.4.0 changes the KernelSU side of its patch and adds a
  new priority filter, and FinaSU does not support them yet
- Same Tracepoint hooks, NoMount v2.2.0, `/proc/kallsyms` filter and installer as 1.8

## If you use BRENE

- Do not configure SUSFS from the FinaSU manager while you use BRENE: both write the same settings
- BRENE applies `su_compat`, `kernel_umount` and `selinux_hide` on every boot; change them from its WebUI
- A `uname -r` with a double hyphen (`5.10.269--N-g...`) comes from BRENE's uname spoofing, which cannot
  find a KMI value in this kernel. Set a custom uname in BRENE

## Compatible ROMs

1.9 exports the same symbol CRCs as 1.8, so the same ROMs are compatible:

- **Compatible:** MistOS 5.1 Beta (20261011 to 20261025) and MistOS 5.0 Alpha 20260914; the latest builds from Keosh with the kernel
  `5.10.269-gki-g1598dc02ea84`: crDroid 12.12 (20260928), Evolution X 11.11, Infinity-X 3.12 (VANILLA,
  GAPPS core and extra), Lunaris 3.12 (VANILLA and GMS), LineageOS 23.2 (20260929) and Axion 2.8 (VANILLA
  and GMS); Infinity-X 4.1 by LF5 (17.10.2026); crDroid 12.12 by Taha Keles (20260930)
- **Not compatible:** AOSPA calcite and PenguinOS celerity. They use their own kernel
  (`5.10.269-beryl-7156c6f9fb`) and the installer stops on them

## Checks

- KMI against clean Equinox: 0 changed CRCs and 0 removed symbols (only `put_pid_ns` is added)
  It exports exactly the same CRCs as r2 and 1.8, so the compatible ROMs stay the same
- Vendor module CRCs match (337 `vendor_boot` and 390 `vendor_dlkm` modules) for MistOS 5.1 Beta 20261025, Project Infinity-X 4.1 and the latest builds from Keosh; AOSPA and PenguinOS are still not compatible
- **Tested on the phone** (POCO F5 Pro, MistOS 5.1 Beta 20261025) by booting this kernel with `fastboot boot`, without flashing it: boots, 385 modules loaded (the same as 1.8), SELinux Enforcing, BBR, NoMount hidden from `/sys/module`, and the FinaSU v1.5.0 manager shows it working (built in, version 33174-6, Tracepoint hooks, NoMount v2.2.0, SUSFS v2.3.0)
- In that test the shell had no root, so `dmesg` and `/proc/kallsyms` were not read on the phone; the kallsyms filter was checked on the built kernel (95 driver symbols left visible, none that reveals root)
